Robo Apollo 

Projeto Integrador – Curso Programador de Sistemas. Equipe multidisciplinar: concepção do produto pela equipe de negócios; desenvolvimento web por Ana Raquel.

✨ Visão Geral

O Robo Apollo é um site de vendas criado para apresentar e comercializar o robô educacional Apollo, produto voltado para pessoas neurodivergentes. O projeto evidencia práticas de desenvolvimento front‑end voltadas à organização de código, reutilização de estilos e clareza na estrutura de pastas.

🎯 Objetivos do Projeto

Expor o produto de forma atraente e responsiva.

Facilitar manutenções separando estilos em múltiplos arquivos CSS.

Preservar organização de mídia e código‑fonte em um repositório versionado (Git).

Demonstrar competências adquiridas no curso: HTML5, CSS3, JavaScript básico e Git/GitHub.

    Por que múltiplos arquivos CSS?Cada seção (cabeçalho, banner, benefícios, depoimentos, rodapé) 
    possui um stylesheet específico, permitindo alterações localizadas sem risco de efeitos colaterais 
    no restante do layout.

    🖥️ Tecnologias Utilizadas

HTML – marcação semântica.

CSS – Flexbox, Grid, animações simples.

JavaScript – eventos de clique, navegação suave, validação básica de formulário.

Git & GitHub – versionamento e hospedagem do código.
